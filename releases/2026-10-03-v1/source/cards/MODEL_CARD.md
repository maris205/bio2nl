# Model inventory: fresh joint-pretraining and source-selected classifiers

This card describes 36 existing checkpoints indexed by metadata/models_assets.json; the package includes no weight bytes. Nine causal-LM checkpoints are EP/ES/EE x PT seeds 0/1/2, trained from fresh initialization. Twenty-seven complete backbone-plus-two-logit-head classifiers add FT seeds 0/1/2 and retain the epoch minimizing full source-validation CE, ties earlier. No smoke checkpoint is listed as a formal model.

The same shared English/protein BPE tokenizer, architecture and total PT input-token budget are used. EP is English+protein, ES English+shuffled protein, EE two English streams. Model initialization, PT/FT seed hierarchy, corpus exposure and fixed numerical regimes are defined by original protocol 60ce5e0518475fb0e4ba8a83d34d45fbe4c89e74e12fb984abbe41c8fd3eff24 and the included aggregate design. PT: 1,024 updates / 16,777,216 input tokens. SFT: 5 epochs / 1,260 updates / 40,220 presentations; source train 8,044, validation 20,276. No old checkpoint was resumed.

Scores are source-validation-selected and exploratory after prior target use. EP source test accuracy approximately 50.76% and QQP balanced accuracy approximately 50.18% mean neither strong learned protein relation competence nor useful fixed-decision English transfer has been demonstrated. The small positive EP-ES ranking contrast across all three PT seeds is descriptive and not a hypothesis-test result. Do not use these checkpoints for biological or medical decisions.

`source-input --kind models --asset-root ROOT` can hash supplied checkpoints at their explicit workspace-relative paths. The default packaging process indexes metadata and does not load, convert or duplicate models. Byte identities are bound to the original source_selection.json hash 48de918e0b4a2b12ac3021072f601e2b1caf61730c77097fa9bfbfc75e15fb4c. The portable model format is implemented in bio2nl/new_data_full_training_v1/model.py; the complete classifier head must be preserved. This release does not yet provide a independently validated public-weight inference command.

Tokenizer redistribution and weight-specific terms remain separate from code and Swiss-Prot dataset terms. OWT text rights are not covered by CC0 packaging. Weight publication remains pending explicit distribution terms and destination; no blanket Apache/CC-BY weight license is invented. HF model repository ID, revision and download readback are unset. The separate historical HF model repo name is not silently reused.
